# Tim-1e Profile README Setup

This folder is intended to become the GitHub profile repository:

```text
Tim-1e/Tim-1e
```

## Required Repository Settings

1. Create a GitHub repository named exactly `Tim-1e`.
2. Upload this folder's contents into that repository.
3. Open `Settings -> Actions -> General`.
4. Under `Workflow permissions`, choose `Read and write permissions`.
5. Run these workflows once from the Actions tab:
   - `GitHub Profile 3D Contrib`
   - `Generate README Stats Cards`

## Tokens

- No custom token is required for the current public-profile version.
- Both workflows use GitHub's built-in `GITHUB_TOKEN`.
- If you later want private contribution data or more advanced GraphQL-based reports, add a personal access token as a repository secret and update the workflows.

## Generated Files

The README references files generated by Actions:

```text
profile-3d-contrib/profile-season-animate.svg
assets/github-stats/stats.svg
assets/github-stats/top-langs.svg
assets/github-stats/pin-*.svg
```

These are committed into the repository so the profile does not depend on the public
`github-readme-stats.vercel.app` deployment (which is frequently paused with `503 DEPLOYMENT_PAUSED`).
